<h1 align="center">MenuDuck</h1>

<p align="center">Утилита для строки меню macOS 26+.</p>

<p align="center">
  <a href="README.md">English</a> ·
  Русский
</p>

- Скрытие и раскрытие иконок, автоскрытие и горячие клавиши.
- Маскировка выреза, настройка углов экрана и перенос строки меню ниже камеры на поддерживаемых экранах.
- Дополнительные плагины: **Stay Awake** не даёт Mac засыпать, **Network Speed** показывает скорость загрузки и отправки. В альфе оба будут бесплатными.

## Альфа

Готовим первую сборку для приглашённых тестеров. Скачать её пока нельзя.

Первые сборки будут без подписи Developer ID и нотариализации Apple. Перед установкой прочитайте [инструкцию](docs/ALPHA_GUIDE.ru.md).
