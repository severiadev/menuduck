# Инструкция тестера MenuDuck

[На главную](../README.ru.md) · [English](ALPHA_GUIDE.md)

Альфа для скачивания пока не опубликована. Инструкция предназначена для проверенной сборки, которая появится в [Releases](https://github.com/severiadev/menuduck/releases).

## Перед установкой

- Нужна macOS 26 или новее. Проверенные модели Mac и ограничения смотрите в описании конкретного релиза.
- Сделайте резервную копию. Не испытывайте ранние функции экрана и обоев во время работы, которую нельзя прервать.
- Получите приглашение, ключ тестера и ожидаемую SHA-256 через личный канал организатора.
- Ранние сборки имеют техническую ad-hoc подпись, но **не подписаны Developer ID и не прошли notarization Apple**. Ad-hoc подпись не подтверждает личность разработчика.

## Установка

1. Откройте конкретный альфа-релиз и прочитайте описание. Скачайте `.dmg` из **Assets**. Архивы **Source code (zip/tar.gz)**, которые показывает GitHub, — не приложение для Mac.
2. Сравните SHA-256 скачанного файла со значением от организатора в личном канале. В Терминале введите `shasum -a 256 `, перетащите DMG в окно и нажмите Return. Команда только читает файл. Должны совпасть все 64 шестнадцатеричных символа. Контрольная сумма только с той же страницы загрузки не является независимым подтверждением подлинности.
3. Откройте DMG, перетащите `menuduck.app` в **Applications / Программы** и извлеките образ диска.
4. Один раз запустите приложение из Программ. Если macOS не может проверить разработчика, продолжайте только после проверки файла и при доверии к источнику.
5. Откройте **System Settings → Privacy & Security → Open Anyway**, затем подтвердите **Open**, если эти действия доступны. В русской macOS ищите раздел конфиденциальности и безопасности и действие открытия заблокированного приложения. Защиту Gatekeeper оставьте включённой.

Если сумма не совпала, macOS сообщает о вредоносном ПО или повреждении либо нужной кнопки нет — **остановитесь и напишите организатору**. Не отключайте Gatekeeper, не удаляйте quarantine, не запускайте обходные скрипты и не обходите ограничения рабочего Mac.

Официальное описание Apple: [Safely open apps on your Mac](https://support.apple.com/en-us/102445).

## Первый запуск

1. Откройте настройки MenuDuck через его иконку в строке меню.
2. Найдите **Enter License Key** и введите ключ, полученный лично. При необходимости разрешите запрос активации. Ключ нельзя прикладывать к публичному отчёту.
3. Откройте каталог плагинов и нажмите **Update Catalog**, когда захотите получить актуальный список. Подтвердите соответствующее сетевое разрешение, если оно запрошено.
4. В опубликованной альфе проверьте установку **Stay Awake** и **Network Speed** — двух Free-плагинов. Остальные должны оставаться Planned. Отсутствующая загрузка — не повод обходить проверки.
5. Нажмите **I Need It** у одного запланированного плагина. Учтённый голос должен отображаться как **Voted**. Проверьте и **Remove Vote**.

## Десятиминутная проверка

- Скройте и раскройте иконки. Попробуйте автоскрытие и назначенное вами сочетание клавиш.
- Меняйте по одной настройке оформления. Проверяйте результат её выключения.
- Если актуально, попробуйте перемещение строки меню, внешний монитор и переключение Spaces. Запишите конфигурацию для отчёта.
- Режим обоев **All (Experimental)** экспериментальный: для маскировки выреза в нём сейчас требуется оформление обоев **Dark**.
- Включите и выключите Stay Awake. Проверьте Network Speed на небольшой загрузке: это монитор текущего трафика, не тест скорости канала.
- Закройте и снова откройте MenuDuck. Проверьте сохранение настроек.
- При проблеме запишите действие, ожидаемый и фактический результат, версию и номер сборки.

## Если возникла проблема

Если приложение отвечает, выключите последнюю изменённую настройку. Если нет — закройте его обычным способом или через принудительное завершение macOS и свяжитесь с организатором. Само закрытие не гарантирует восстановления любого состояния экрана или обоев.

Не удаляйте настройки, сохранённые обои и данные восстановления ради эксперимента: они могут понадобиться для возврата предыдущего состояния. Перед публикацией диагностики проверьте и удалите личные сведения.

Перед обновлением прочитайте описание новой сборки, закройте приложение и следуйте инструкции релиза. Автоматического обновления приложения в альфе нет. Не устанавливайте более старую версию без согласования.
